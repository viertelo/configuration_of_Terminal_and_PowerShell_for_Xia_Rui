# 备份与历史资料说明

本目录包含仓库保留的历史资料与脚本在本机产生的备份，不能仅凭目录名称判断是否适合恢复。当前操作说明见[部署与回退](../部署与回退.md)。

| 内容 | 用途 |
| --- | --- |
| `original/` | 最初的配置和美化说明，保留原貌供比较，不代表当前功能或安装建议 |
| `deployment-20260907-*` | 当时的部署快照，含机器路径和旧版本源码，部分作为隔离回归测试输入 |
| `install-backup-*` | 安装 / 部署运行时创建的组件快照，以清单内容为准；默认由 Git 忽略 |
| `system-audit-*` | 系统审计采集资料，不是 Restore-All 可直接恢复的标准组件快照 |
| `pre-rollback-*`（快照内） | 恢复前保存的当前内容与 restore-status.json，用于失败排查和救援 |

新格式使用 `manifest.json`，由当前仓库的 Restore-All / TerminalState 校验；旧双文件格式使用 `deployment.json`，由当前仓库的 Manage-TerminalConfiguration 处理。两种格式的文件名、目标范围和参数支持不同。

不要修改快照中的原始文件或哈希以让校验通过，也不要执行快照内保存的旧脚本。克隆下来的日期快照与 `.deployment-path` 可能包含作者机器路径，不是新机器的恢复点。历史文档中的绝对路径和测量只表示当时环境。

`original/` 和日期快照保留不变，文档更正在根目录维护文档及历史报告说明中记录，以免破坏审计证据和测试输入。整理旧备份前，先确认仍需使用的指针、原快照、救援目录和测试依赖。
